# Guide Screenshots Directory

This folder contains screenshots for the ChickadeeX Demo Guide page.

## Required Screenshots

Place the following screenshot files in this directory:

1. **step-1-access-demo.png**
   - Show the sidebar with "Demo" highlighted
   - Capture the navigation to the Demo workspace

2. **step-2-upload-image.png**
   - Show the Upload button and drag-drop area
   - Display the file selection dialog or drag overlay

3. **step-3-manage-uploads.png**
   - Show the Upload dropdown menu with uploaded images
   - Display image list with delete buttons

4. **step-4-generate-report.png**
   - Show the "Generate" button in the report panel
   - Capture the AI generation in progress

5. **step-5-edit-content.png**
   - Show the Findings and Impression text fields
   - Display edited content with "Unsaved changes" indicator

6. **step-6-save-report.png**
   - Show both "Save Report" and "Save" buttons
   - Display the saved confirmation

7. **step-7-version-history.png**
   - Show the version dropdown with multiple versions
   - Display version numbers and latest marker

8. **step-8-draft-reports.png**
   - Show the Reports sidebar item and Draft tab
   - Display the draft reports list

9. **step-9-edit-finalize-delete.png**
   - Show a report detail page
   - Display edit, finalize, and delete options

10. **step-10-finalize.png**
    - Show the finalize confirmation
    - Display a finalized report in the Finalized tab

## Image Guidelines

- **Format**: PNG preferred (supports transparency)
- **Size**: Recommended width 800-1200px
- **Quality**: High resolution for clarity on all screens
- **Annotations**: Add arrows or highlights to focus user attention
- **Consistency**: Use the same browser window size for all screenshots
- **Privacy**: Ensure no sensitive data appears in screenshots

## Usage

Screenshots are automatically referenced in the Guide page component. The component will display placeholders until you add the actual images.

To add an image:
1. Take the screenshot following the guidelines above
2. Save it with the exact filename listed above
3. Place it in this directory
4. Refresh the Guide page to see the image
